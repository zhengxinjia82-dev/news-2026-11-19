## The image

`entry.png` (1024×1024) is drawn programmatically with Python and PIL: a header naming the day, and a 2×2 grid of four story panels — diplomacy, Europe, justice, and tech — each with its own flat-colour icon, headline and short body text. `main.ts` copies it to the output directory.
